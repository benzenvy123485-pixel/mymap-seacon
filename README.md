# MyScape — ตู้ประชาสัมพันธ์ แผนผังร้านค้า 3 มิติ

จอทีวีแนวตั้ง 9:16 ทัชสกรีน ตั้งที่จุดประชาสัมพันธ์ในโซน MyScape ซีคอนสแควร์
ครึ่งบนเป็นแผนผัง 3 มิติหมุนได้ ครึ่งล่างเป็นช่องค้นหาและตารางร้าน
จิ้มร้านแล้วกล้องบินไปหาร้านนั้น พร้อมเส้นทางเดินจากจุดที่ตู้ตั้งอยู่

**สถานะ: ตัวอย่างระบบ — ชื่อร้านทั้ง 50 ร้านเป็นของสมมติ ผังเป็นค่าประมาณ**

ทำเสร็จแล้วชั้นเดียวคือ **L1 My Pulse** อีกสามชั้นเตรียมช่องไว้ ขึ้น "เร็วๆ นี้"

## ขึ้น GitHub แล้วต่อ Vercel

### สิ่งที่ต้องมีก่อน
- บัญชี GitHub
- บัญชี Vercel (สมัครด้วยบัญชี GitHub ได้เลย จะได้ไม่ต้องต่อสิทธิ์ทีหลัง)
- โปรแกรม `git` ในเครื่อง ถ้าไม่มีก็ใช้วิธีลากไฟล์วางบนเว็บ GitHub แทนได้

### ถ้าเป็น repo ใหม่

```bash
cd myscape-kiosk
git init
git add index.html index-offline.html README.md
git commit -m "MyScape L1 My Pulse kiosk map"
git branch -M main
git remote add origin https://github.com/<ชื่อบัญชี>/myscape-kiosk.git
git push -u origin main
```

### ถ้าใช้ repo เดิมแล้วเอาของใหม่ทับ

```bash
cd <repo เดิม>
git rm index.html                 # ของเก่ายังอยู่ในประวัติ ย้อนกลับได้
cp <ที่เก็บไฟล์ใหม่>/index.html .
cp <ที่เก็บไฟล์ใหม่>/index-offline.html .
cp <ที่เก็บไฟล์ใหม่>/README.md .
git add -A
git commit -m "แทนที่ด้วยแผนผัง MyScape L1 My Pulse"
git push
```

อยากได้ของเก่าคืนเมื่อไหร่ `git log -- index.html` แล้ว `git checkout <commit> -- index.html`

### ตั้งค่าบน Vercel

vercel.com → **Add New** → **Project** → เลือก repo
→ Framework Preset เลือก **Other**
→ Build Command และ Output Directory **เว้นว่างทั้งคู่**
→ **Deploy**

ไม่ต้องตั้ง environment variable ไม่ต้องมี `vercel.json`

**ถ้าขึ้น 404** แปลว่า `index.html` ไม่ได้อยู่ที่รากของ repo
แก้ที่ Settings → General → Root Directory

หลังจากนี้ push ทีไร deploy ให้เองทุกครั้ง และย้อนเวอร์ชันเก่าได้จากแท็บ Deployments

## ตั้งค่าเครื่องหน้างาน

- เปิดเต็มจอด้วย `F11` หรือรัน `chrome --kiosk --incognito <URL>`
- **ปิด screensaver และ sleep ของเครื่อง**
- ตั้งจอเป็นแนวตั้ง 1080×1920 หรือสูงกว่า ระบบปรับสัดส่วนเองทุกขนาด
- ไม่มีคนแตะ 60 วินาที กล้องจะเริ่มหมุนรอบชั้นช้าๆ เป็นโหมดดึงคน

**แนะนำให้ใช้สองชั้น** ขึ้น Vercel เป็นตัวหลัก และเก็บ `index-offline.html` ไว้ในเครื่องเป็นตัวสำรอง
วันที่เน็ตห้างมีปัญหา คนที่โดนลูกค้าถามคือพนักงานประชาสัมพันธ์ ไม่ใช่ฝ่าย IT

## จุดที่ต้องแก้เมื่อได้ข้อมูลจริง

ทุกอย่างอยู่ในบล็อกที่ 1 และ 2 ของ `<script>`

| ตัวแปร | แก้อะไร |
|---|---|
| `TENANTS` | รายชื่อร้าน `[เลขยูนิต, ชื่อ, อักษรย่อ, หมวด, คำโปรย]` |
| `AREA` | ตารางเมตรของแต่ละยูนิต ตอนนี้ใช้ค่าจากเอกสารโครงการ |
| `ROWS` `PLATE_PX` | รูปทรงผังและตำแหน่งยูนิต — เปลี่ยนทั้งบล็อกเมื่อได้ DXF |
| `YOU_PX` | พิกัดจุดที่ตั้งตู้ ถ้ามีหลายตู้ต้องตั้งแยกทีละตัว |
| `NODES_PX` `EDGES` | แนวทางเดินและจุดเชื่อม ใช้หาเส้นทางสั้นที่สุด |
| `FLOORS` | เปลี่ยน `ready:false` เป็น `true` เมื่อชั้นนั้นมีผังแล้ว |

พิกัดทั้งหมดเก็บเป็นหน่วยพิกเซลของภาพผังต้นฉบับ แล้วแปลงเป็นเมตรตอนโหลด
สเกลอยู่ที่ `PLAN.s` = 19.3 px ต่อเมตร

การ์ดโมโนแกรมออกแบบให้ใส่โลโก้จริงแทนตัวอักษรย่อได้เลย ไม่ต้องรื้อ layout

## ข้อจำกัดที่ต้องรู้

- **ตำแหน่งร้านคลาดเคลื่อนระดับเมตร** เพราะลอกจากภาพผังในเอกสาร ไม่ใช่ไฟล์ CAD
  ระยะเดินที่แสดงบนจอใช้ดูคร่าวๆ ได้ ห้ามใช้อ้างอิงจริง
- **หกยูนิตริมโถงกลาง (1125–1130) กล่องเล็กกว่าของจริงราว 37%** เพราะในผังเป็นรูปลิ่ม
  ไม่ใช่สี่เหลี่ยม ตัวเลขตารางเมตรที่แสดงในแผงยังเป็นค่าจากเอกสาร ไม่ได้คำนวณจากกล่อง
- อีก 44 ยูนิตขนาดตรงกับเอกสารคลาดไม่เกิน 2%
- **ยังไม่มีห้องน้ำ ลิฟต์ บันไดเลื่อน ATM ที่จอดรถ** ซึ่งเป็นคำถามอันดับหนึ่งที่เคาน์เตอร์
  และพอทำครบสี่ชั้นจะกลายเป็นของบังคับ เพราะบันไดเลื่อนคือเส้นทางข้ามชั้น
- ยังไม่มีปุ่มสลับภาษา ไทย/EN ถ้าจะทำต้องวางโครงตั้งแต่ต้น

## สิ่งที่ต้องขอจากห้าง

**ไฟล์ DXF ของผังแต่ละชั้น พร้อมเลขยูนิตกำกับ**
(`.dwg` อ่านไม่ได้ ต้อง Save As เป็น `.dxf` ก่อน · `.svg` ก็ใช้ได้ดี)

**คำถามที่ยังไม่มีคำตอบ**
- ตู้จะตั้งกี่จุด ตรงไหนบ้าง (`YOU_PX` ต้องตั้งแยกทีละตู้)
- ตำแหน่งบันไดเลื่อนและลิฟต์ที่แน่นอน
- ชั้น 4 เรียก MyDineScape หรือ My Indulgence — เอกสารใช้สองชื่อ
- **ใครเป็นเจ้าภาพอัปเดตเมื่อร้านย้าย** ข้อนี้สำคัญที่สุด
  ทางออกที่ควรเสนอไปพร้อมกัน: แยกรายชื่อร้านเป็น `shops.json` ให้ฝ่ายเช่าพื้นที่แก้เองได้

## สีและฟอนต์

แก้ที่บล็อก `:root` บรรทัดบนสุดของ `<style>` จุดเดียว สีทั้งงานเปลี่ยนตาม
โทนครีม–เทอร์ราคอตต้าถอดมาจากเอกสารแบรนด์ MyScape
ก้อนตึกในภาพ 3 มิติใช้สีเดียวกับกล่องยูนิตในผังสถาปนิก เพื่อให้คนโยงภาพกลับไปหาผังได้

ฟอนต์ใช้ **Prompt** ทั้งงาน สร้างลำดับความสำคัญด้วยน้ำหนักตัวอักษรและระยะห่าง
ไม่ใช่ด้วยการสลับฟอนต์ ถ้าจะเปลี่ยนแก้ที่ `--f-display` กับ `--f-body`
(ถ้าใช้ `index.html` ต้องแก้ลิงก์ Google Fonts บรรทัดบนด้วย)
