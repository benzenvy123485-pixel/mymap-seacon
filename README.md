## วิธีที่ 1 · GitHub + Vercel (แนะนำถ้ามีหลายคนดูแล)

```bash
cd mall-lux
git init
git add index.html README.md
git commit -m "Seacon kiosk floor map"
git branch -M main
git remote add origin https://github.com/<ชื่อบัญชี>/seacon-kiosk-map.git
git push -u origin main
```

จากนั้น vercel.com → **Add New** → **Project** → เลือก repo
→ Framework Preset เลือก **Other** → Build Command กับ Output Directory **เว้นว่าง** → **Deploy**

ข้อดีคือ push ทีไร deploy ให้เองอัตโนมัติ ย้อนกลับเวอร์ชันเก่าได้ และแก้จากที่ไหนก็ได้

## ข้อเสนอของบ๊วยสำหรับตู้จริง

**อย่าเลือกอย่างใดอย่างหนึ่ง ใช้สองชั้น**

1. ขึ้น Vercel เป็นตัวหลัก เปิดจาก URL ตามปกติ
2. ก๊อป `index-offline.html` ใส่เครื่องไว้ด้วย ตั้งเป็นหน้า fallback

เหตุผลคือตู้ประชาสัมพันธ์ตั้งอยู่หน้าลูกค้าทั้งวัน วันที่เน็ตห้างมีปัญหา
คนที่โดนถามคือพนักงานประชาสัมพันธ์ ไม่ใช่ฝ่าย IT
มีไฟล์สำรองในเครื่องแปลว่าจอไม่มีวันขึ้นหน้าขาว

## ตั้งค่าเครื่องหน้างาน

- เปิดเต็มจอด้วย `F11` หรือรัน `chrome --kiosk --incognito <URL>`
- **ปิด screensaver และ sleep ของเครื่อง**
- ตั้งจอเป็นแนวตั้ง 1080×1920 หรือสูงกว่า ระบบปรับสัดส่วนเองทุกขนาด
- ไม่มีคนแตะ 60 วินาที กล้องจะเริ่มหมุนรอบห้องช้าๆ เป็นโหมดดึงคนเข้ามา

## จุดที่ต้องแก้เมื่อได้ข้อมูลจริง

ทุกอย่างอยู่ในบล็อกที่ 1 และ 2 ของ `<script>` ในไฟล์

| ตัวแปร | แก้อะไร |
|---|---|
| `TENANTS` | รายชื่อร้าน `[ชื่อ, อักษรย่อ, หมวดย่อย, คำอธิบาย]` |
| `CATEGORIES` | เปลี่ยน `ready:false` เป็น `true` เมื่อหมวดนั้นมีข้อมูลแล้ว |
| `YOU` | พิกัดจุดที่ตั้งตู้ ถ้ามีหลายตู้ต้องตั้งแยกทีละตัว |
| `HALL` `SEAT` `RING` | รูปร่างห้อง โซนที่นั่ง และแนวทางเดิน |

ตำแหน่งร้านตอนนี้โค้ดคำนวณเองจากจำนวนร้านต่อแถว
พอได้ไฟล์ **DXF** ของผังจริง จะเปลี่ยนเป็นพิกัดจริงของแต่ละยูนิต

การ์ดโมโนแกรมออกแบบให้ใส่โลโก้จริงแทนตัวอักษรย่อได้เลย ไม่ต้องรื้อ layout

## สีและฟอนต์

แก้ที่บล็อก `:root` บรรทัดบนสุดของ `<style>` จุดเดียว สีทั้งงานเปลี่ยนตาม

ฟอนต์ใช้ **Prompt** ทั้งงาน สร้างลำดับความสำคัญด้วยน้ำหนักตัวอักษรและระยะห่าง
ไม่ใช่ด้วยการสลับฟอนต์ ถ้าจะเปลี่ยนแก้ที่ `--f-display` กับ `--f-body`
(ถ้าใช้ `index.html` ต้องแก้ลิงก์ Google Fonts บรรทัดบนด้วย)
